# Variables du Template HTML

## 📋 Vue d'ensemble

Ce document liste toutes les variables identifiées dans le template qui peuvent être personnalisées pour générer des pages pour différentes villes.

---

## 🏙️ VARIABLES PRINCIPALES

### 1. **NOM_VILLE**
Exemple actuel: `Helsinki`
- Utilisé dans: titre principal, logo, texte SEO, noms de fonctions JavaScript
- Occurrences clés:
  - `<title>Kypsät Seksitreffit Helsinki`
  - `<h1>Kypsät Seksitreffit Helsinki</h1>`
  - `<div class="logo-text">Treffit Helsinki</div>`
  - JavaScript: `showHelsinkiPopup()`, `closeHelsinkiPopup()`, etc.

### 2. **CLASSE_CONTAINER**
Exemple actuel: `helsinki-dating-container`
- Classe CSS racine pour toute la page
- À remplacer par: `{ville}-dating-container`

### 3. **ID_POPUP**
Exemple actuel: `helsinki-popup`
- ID du popup d'inscription
- À remplacer par: `{ville}-popup`

### 4. **TIMER_VARIABLE**
Exemple actuel: `helsinkiTimeLeft`, `helsinkiTimerInterval`
- Variables JavaScript pour le timer
- À remplacer par: `{ville}TimeLeft`, `{ville}TimerInterval`

## 🔧 ÉLÉMENTS TECHNIQUES À MODIFIER

### JavaScript:
1. **Nom des fonctions**:
   - `showHelsinkiPopup()` → `show{Ville}Popup()`
   - `closeHelsinkiPopup()` → `close{Ville}Popup()`
   - `formatHelsinkiTime()` → `format{Ville}Time()`
   - `updateHelsinkiTimer()` → `update{Ville}Timer()`

2. **Variables**:
   - `helsinkiTimeLeft` → `{ville}TimeLeft`
   - `helsinkiTimerInterval` → `{ville}TimerInterval`

3. **ID d'éléments**:
   - `helsinki-popup` → `{ville}-popup`
   - `helsinki-timer` → `{ville}-timer`

### CSS:
- Classe principale: `.helsinki-dating-container` → `.{ville}-dating-container`
